# static-app

Стартовый HTML/CSS/JS-скелет для блоков 1–4 курса (HTML, CSS, JS-минимум, DOM, события и интерактивность).

Зависимости и сборщики не требуются — откройте `index.html` в браузере напрямую или через расширение VSCode "Live Server" (автообновление при сохранении).

## Структура

- `index.html` - базовый каркас страницы (шапка, навигация-заглушка, основной контент, подвал)
- `css/style.css` - CSS-reset и базовые переменные (цвета, отступы, шрифты)
- `js/app.js` - пустой файл для вашей логики, уже подключён в конце `index.html`

## Что делать на каждом блоке

- **Блок 2** (HTML + CSS): разметить и стилизовать страницы «Авторизация» и «Профиль» внутри `<main class="app-main">`.
- **Блок 4** (DOM + события): добавить в `js/app.js` проверку логина/пароля, ручное переключение «страниц» и вывод оценок из JS-массива.

Подробности — в методичке соответствующей лабораторной работы.
